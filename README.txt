CONNECT V818 — CROWN BOT ANIMATED DEMO

GET STARTED
1. Extract the entire ZIP. Do not open the HTML inside the ZIP viewer.
2. Open Connect_V818_Crown_Bot.html in Chrome or Edge.
3. Keep the assets folder beside the HTML.

For GitHub Pages or another static host, upload the HTML and the complete assets
folder together. You can rename the HTML to index.html if it is the site's home
page. All mascot paths are relative; there are no temporary download links.

The ordinary demo and mascot can open locally. Microphone recording requires
HTTPS or localhost and browser permission. Existing connected AI features still
require their existing connection. No connection or credential was changed.

TRY CROWN BOT
Click Crown Bot to open the existing chat. Enter or Space also activates him.
Use the small crown controls button to open his existing settings. Under
Animation & sound, expand Animation tester to preview all 36 poses, random idle
actions, an unread-board reaction, image fallback, and reduced motion.

Pause animation is available in the same settings. System reduced-motion
preferences are always respected. The existing size, drag, dock, quiet-mode,
and notification controls remain available.

WHAT IS INCLUDED
- Complete V818 HTML, based on the supplied V817 demo.
- All 36 original transparent animated WebP files.
- All 36 original PNG animation posters.
- Original bubble WAV soundtrack, recovered from the earlier animation work.
- animations.json mapping with the soundtrack entry, and integration notes.

The optional WebM alternatives, opaque MP4 previews, and 2048px static pose pack
are not required for this player and are not included. The original supplier
manifest retains those alternative-format mappings; playback uses only its
WebP and poster entries.

SOUND / POSSIBLE ADDITIONAL ARTWORK
Bubble sound starts OFF each time the page opens. Enable it in Crown Bot controls,
then preview Idle / Bubble Boop to hear it. Only one audio source is played.
The three-second WAV was recovered from the separately saved sound update; it
was not present in the attached animation ZIP. Other poses remain silent.

Working / Analyzing is used for active meeting recording and processing.
Thinking represents a paused meeting. A dedicated Listening / Transcribing
pose with a microphone or waveform would be a useful optional addition.
No required mascot artwork or sound assets are missing from this package.

VERIFICATION LIMIT
Asset decoding, transparency, timing, JavaScript syntax, controller behavior,
real task-event hooks, and responsive geometry were checked. The browser preview
service could not open the local demo; live visual checks in light/dark themes,
on mobile, and with a microphone were not completed in this environment.

See INTEGRATION_NOTES.md for the event mapping and verification details.
